# AppleBacon

[English](README.md) · **한국어**

AppleBacon(사과맛 베이컨)은 **헬다이버즈 2**에서 이미 가진 갑옷으로 나만의 갑옷을 만드는 모드입니다. 한 갑옷의 **외형**, 다른 갑옷의 **기본 능력치**, 또 다른 갑옷의 **패시브**를 골라 조합을 저장하고 입을 수 있습니다.

AppleBacon은 단독으로 동작합니다. Bingus Shared Loader 같은 로더가 필요 없고, 다른 모드 때문에 로더를 설치해 두어도 함께 쓸 수 있습니다.

## 기능

- 보유한 외형, 기본 능력치, 패시브를 **자유롭게 조합**해 변형으로 저장합니다.
- **상세 패널에서 바로 편집**: 갑옷을 고르고 **+**를 누르면 그 갑옷이 외형이 됩니다. **통계** 상자나 **방어구 패시브** 상자를 눌러 원하는 순서로 바꿉니다.
- 이름이 붙은 **패시브 아이콘 목록**, 눈금이 있는 **능력치 표**, 마우스 휠 스크롤, 마우스를 올리면 강조 표시.
- **게임과 같은 디자인**: 게임이 한국어면 패널 문구도 한국어로 나옵니다.
- **패드 지원**(XInput / Steam Input): 방향키·스틱 이동, A 선택, B 뒤로, Y 취소, LB/RB 이동.
- 저장한 변형은 재시작 후에도 남고, 출격 전 장비 화면에서도 고를 수 있습니다.
- **내 컴퓨터에서만** 동작합니다. 다른 플레이어는 설치하지 않아도 됩니다.

보유한 장비끼리만 조합할 수 있고, 새로 해금되는 것은 없습니다.

## 설치

1. 게임을 끕니다.
2. **Arsenal**에서 `AppleBacon-<버전>.zip`을 가져와 켭니다.
3. **Purge / Deploy** 후 게임을 켭니다.
4. **무기고 → 방어구**를 엽니다. 맨 위에 저장한 변형과 **+** 카드가 있습니다.

## 사용법

1. 갑옷을 클릭해 고른 뒤 **+ (변형 만들기)**를 누릅니다. 그 갑옷이 외형이 됩니다.
2. 상세 패널의 **통계**를 눌러 능력치를, **방어구 패시브**를 눌러 패시브를 고릅니다. 지금 고르는 상자는 노란색으로 표시됩니다.
3. 외형을 바꾸려면 **외형** 줄을 누릅니다.
4. **생성**을 누르면 저장됩니다. 새 카드를 고르고 게임의 **장비** 버튼을 누르면 입습니다.

저장한 변형을 바꾸려면 카드를 고르고 **변형 수정**을 누르세요. 외형·능력치·패시브가 그대로 채워진 채 열리고, **저장**하면 덮어써집니다. 입고 있던 변형이라면 다시 장착해야 바뀐 내용이 적용됩니다. **변형 삭제**로 지울 수도 있습니다.

## 설정 (Arsenal → 옵션)

| 옵션 | 기본값 | 설명 |
| --- | --- | --- |
| 기본 능력치 | 따로 고르기 | 끄면 능력치가 항상 외형을 따라갑니다. |
| 헬멧·망토 변형 | 켜짐 | 다른 모드로 헬멧·망토에 패시브가 있을 때 같은 방식으로 만들 수 있습니다. |
| 갑옷 카드 패시브 아이콘 | 켜짐 | 카드에 패시브를 작은 배지로 보여 줍니다. |

## 파일과 삭제

저장 위치: `%LOCALAPPDATA%\AppleBacon\Data`
로그: `%LOCALAPPDATA%\AppleBacon\Logs\AppleBacon.log` (Data 폴더의 `STATUS.txt`에 마지막 시작 결과가 적힙니다)

삭제하려면 모드 관리자에서 AppleBacon을 끄고 Deploy 하세요. 다시 설치할 때를 위해 `%LOCALAPPDATA%\AppleBacon` 폴더는 남겨 둡니다. 변형까지 지우려면 이 폴더를 직접 지우세요.

## 알아두기

- AppleBacon은 게임의 작은 스크립트 `core/wwise/lua/wwise_bank_reference`를 통해 시작합니다. 그 스크립트의 게임 원본 코드를 먼저 그대로 실행한 뒤 AppleBacon을 시작합니다. 게임 업데이트로 이 스크립트가 바뀌면 AppleBacon도 업데이트가 필요합니다.
- 모든 조합의 전투 중 동작을 검증한 것은 아닙니다. AppleBacon은 무기고에서 게임이 보여 주는 값까지만 확인합니다.
- 테스트한 게임 버전: Steam 빌드 25480438.
